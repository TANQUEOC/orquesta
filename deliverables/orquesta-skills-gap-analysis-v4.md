# ORQUESTA · Skills más especializados · Gap analysis v4

## Mejora aplicada en esta fase
Después de reforzar operación, análisis y evaluación, el siguiente hueco visible era la verticalización.

ORQUESTA ya tenía criterio general bueno, pero le faltaba una primera adaptación explícita a un tipo de cliente muy frecuente:
- pymes de servicios

## Por qué esta vertical primero
Porque encaja muy bien con lo ya construido:
- captación
- onboarding
- control
- operaciones

Y porque muchas implantaciones iniciales de ORQUESTA tienen sentido precisamente en:
- agencias
- consultoras
- despachos
- estudios
- equipos pequeños de servicio o soporte

## Mejora aplicada
Se creó la skill:
- `orquesta-servicios-pymes`

Y se reforzó el router para poder derivar casos donde el reto no es solo de proceso, sino de adaptación a la realidad de una pyme de servicios.

## Beneficio esperado
- más especialización visible
- mejor aterrizaje sectorial
- menos respuestas demasiado genéricas
- más criterio realista de implantación
- mejor secuencia para clientes con recursos limitados

## Siguiente hueco probable
Después de esta verticalización inicial, los siguientes huecos visibles podrían ser:
1. otra vertical prioritaria concreta (por ejemplo taller técnico, cerámica, despacho o soporte)
2. skill de dirección comercial / venta consultiva
3. skill de growth más orientada a negocio que a canal o contenido
