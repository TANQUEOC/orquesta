# Resumen ejecutivo · ORQUESTA v2 · Captación v1

## Qué es
Primer caso de uso formal de ORQUESTA v2 para el pilar de captación.

## Para qué sirve
Sirve para diseñar un sistema de captación de leads serio, medible y reutilizable.

## Qué deja resuelto
- objetivo de negocio
- flujo de captación
- datos mínimos
- automatizaciones prioritarias
- métricas
- riesgos
- roadmap de implantación

## Qué no hace todavía
No deja una automatización técnica cerrada ni un CRM definitivo. Eso sería la siguiente iteración.

## Valor para Orquesta
Este caso es una pieza base porque la captación es una puerta de entrada clara para vender, demostrar método y generar un proceso repetible.

## Siguiente movimiento recomendado
Bajar este caso a una implantación concreta con stack elegido y entregable técnico.
