# Checklist de ejecución

## Día 1
- [ ] Estados operativos comunes definidos
- [ ] Fases mínimas vigiladas definidas
- [ ] Bloqueos relevantes listados
- [ ] Incidencias base definidas
- [ ] Responsables y prioridades definidos

## Día 2
- [ ] Hoja maestra o base operativa creada
- [ ] Tabs principales creadas
- [ ] Columnas mínimas definidas
- [ ] Estados, prioridad y responsable configurados
- [ ] Relaciones básicas cerradas

## Día 3
- [ ] Workflow n8n de señales preparado
- [ ] Detección de cambios de estado validada
- [ ] Registro de incidencias validado
- [ ] Registro de bloqueos validado
- [ ] Avisos internos validados
- [ ] Seguimiento mínimo activo

## Día 4
- [ ] Vista resumen de estados creada
- [ ] Vista de bloqueos creada
- [ ] Vista de prioridades creada
- [ ] Vista de casos activos creada
- [ ] Indicadores mínimos visibles

## Día 5
- [ ] Casos reales o simulados probados
- [ ] Avisos internos probados
- [ ] Claridad del tablero revisada
- [ ] Fallos corregidos
- [ ] Uso mínimo documentado
- [ ] Backlog v2 priorizado
