# ORQUESTA v3 · Handoff técnico · Captación → Onboarding v1

## Qué es este paquete
Este paquete define la unión técnica y funcional entre los pilares de Captación y Onboarding en ORQUESTA.

Su propósito es evitar que ambos módulos vivan como piezas aisladas.

## Objetivo
Dejar definido un handoff claro, trazable y automatizable entre:
- el cierre comercial o conversión de una oportunidad
- y el arranque operativo del cliente en onboarding

## Qué resuelve
- evita pérdida de contexto entre comercial y arranque
- evita rehacer a mano información ya recogida en captación
- define qué evento dispara el onboarding
- define qué datos deben pasar
- define qué estados cambian
- deja una base técnica para automatizar el traspaso

## Contenido del paquete
- `handoff-funcional.md`
- `contrato-de-datos.md`
- `maquina-de-estados.md`
- `flujo-tecnico.md`
- `checklist-implantacion.md`

## Resultado esperado
Al usar este paquete, ORQUESTA debe poder conectar Captación y Onboarding como una cadena operativa continua y no como dos procesos independientes.
