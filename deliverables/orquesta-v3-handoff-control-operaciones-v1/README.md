# ORQUESTA v3 · Handoff técnico · Control operativo y reporting → Operaciones v1

## Qué es este paquete
Este paquete define la unión técnica y funcional entre los pilares de Control operativo y reporting y Operaciones en ORQUESTA.

Su propósito es evitar que un caso visible y priorizado quede sin transformarse en trabajo real ejecutable.

## Objetivo
Dejar definido un handoff claro, trazable y automatizable entre:
- un caso activo controlado y priorizado
- y su entrada en la capa de operaciones

## Qué resuelve
- evita que control sea solo observación sin ejecución
- define qué evento dispara la operación
- define qué datos deben pasar
- define qué estados cambian
- deja una base técnica para automatizar el traspaso

## Contenido del paquete
- `handoff-funcional.md`
- `contrato-de-datos.md`
- `maquina-de-estados.md`
- `flujo-tecnico.md`
- `checklist-implantacion.md`

## Resultado esperado
Al usar este paquete, ORQUESTA debe poder conectar Control y Operaciones como una cadena continua entre visibilidad y ejecución.
