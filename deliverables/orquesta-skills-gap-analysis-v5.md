# ORQUESTA · Skills más especializados · Gap analysis v5

## Mejora aplicada en esta fase
Después de operación, análisis, evaluación y verticalización, el siguiente hueco visible estaba en la parte comercial.

ORQUESTA tenía ya buena base de captación, pero faltaba una skill más específica para:
- discovery
- cualificación
- priorización comercial
- objeciones
- avance hacia cierre

## Hueco detectado
Captación resolvía bien el flujo y la estructura de entrada, pero no cubría con suficiente finura la capa consultiva de venta.

Faltaba una skill reusable para:
- distinguir interés de oportunidad real
- detectar dolor serio
- ordenar pipeline con criterio
- responder objeciones sin vender humo
- dejar siguiente paso comercial claro

## Mejora aplicada
Se creó la skill:
- `orquesta-venta-consultiva`

Y se reforzó el router para clasificar mejor situaciones comerciales de:
- discovery
- propuesta
- objeción
- priorización de cuentas
- movimiento hacia cierre

## Beneficio esperado
- más calidad comercial
- menos oportunidades mal calificadas
- mejor avance de cuenta
- más claridad entre curiosidad y oportunidad real
- mejor encaje entre Captación y conversación comercial

## Siguiente hueco probable
Después de esta mejora, los siguientes huecos visibles podrían ser:
1. growth orientado a negocio y revenue
2. nueva vertical sectorial concreta
3. skill de dirección operativa o founder mode más transversal
