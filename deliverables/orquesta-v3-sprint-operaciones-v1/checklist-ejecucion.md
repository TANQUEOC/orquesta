# Checklist de ejecución

## Día 1
- [ ] Modelo operativo base definido
- [ ] Tipos de tarea definidos
- [ ] Responsables posibles definidos
- [ ] Estados operativos definidos
- [ ] Dependencias y bloqueos típicos definidos

## Día 2
- [ ] Hoja maestra o base operativa creada
- [ ] Tabs principales creadas
- [ ] Columnas mínimas definidas
- [ ] Estados, responsable, prioridad y dependencia configurados
- [ ] Relaciones básicas cerradas

## Día 3
- [ ] Workflow n8n de entrada operativa preparado
- [ ] Activación desde control validada
- [ ] Creación de tareas validada
- [ ] Handoffs internos validados
- [ ] Bloqueos iniciales validados
- [ ] Avisos internos validados

## Día 4
- [ ] Vista de operaciones activas creada
- [ ] Vista de tareas abiertas creada
- [ ] Vista de bloqueos operativos creada
- [ ] Vista de responsables o cargas creada
- [ ] Indicadores mínimos visibles

## Día 5
- [ ] Casos reales o simulados probados
- [ ] Estados y cierres probados
- [ ] Claridad del sistema revisada
- [ ] Fallos corregidos
- [ ] Uso mínimo documentado
- [ ] Backlog v2 priorizado
