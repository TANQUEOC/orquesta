# Alcance y resultado esperado

## Alcance
Este sprint cubre la implantación de una versión v1 real del sistema de Onboarding de ORQUESTA sobre un stack pragmático basado en:

- Google Forms
- Google Sheets
- Gmail
- n8n

## Qué incluye
- conexión de la entrada real del onboarding
- configuración del workflow productivo
- generación de checklist de arranque
- registro de estados
- solicitud de datos, materiales o accesos
- aviso interno y seguimiento
- prueba real extremo a extremo
- cierre mínimo operativo

## Qué no incluye por defecto
- portal de cliente completo
- CRM avanzado de customer success
- gestión documental compleja
- automatización enterprise completa de proyectos
- reporting ejecutivo avanzado del onboarding

## Resultado esperado
Al finalizar, el cliente debe tener una capacidad real de onboarding operando con una lógica clara:

1. entra el nuevo cliente
2. el sistema recoge lo necesario
3. el sistema solicita o prepara el arranque
4. el sistema registra el estado
5. el equipo recibe señal
6. el proceso queda trazado

## Resultado de negocio esperado
- menos caos tras la venta
- más velocidad de arranque
- menos olvidos de accesos o materiales
- mejor trazabilidad interna
- mejor preparación para operación posterior
