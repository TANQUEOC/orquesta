# Checklist de ejecución

## Día 1
- [ ] Formulario o ficha de onboarding validado
- [ ] Hoja real de respuestas identificada
- [ ] Campos obligatorios confirmados
- [ ] Estados base definidos
- [ ] Accesos y materiales obligatorios listados

## Día 2
- [ ] Workflow de onboarding montado o importado en n8n
- [ ] Credencial de Google Sheets configurada
- [ ] Credencial de Gmail configurada
- [ ] Lectura de hoja validada
- [ ] Registro en base maestra validado
- [ ] Comunicación inicial validada

## Día 3
- [ ] Estados de onboarding definidos
- [ ] Bloqueos típicos definidos
- [ ] Avisos internos preparados
- [ ] Criterio de handoff documentado
- [ ] Trazabilidad mínima activa

## Día 4
- [ ] Test real con 1 o 2 onboardings
- [ ] Datos capturados correctamente
- [ ] Email o solicitud validada
- [ ] Checklist generada
- [ ] Estado actualizado
- [ ] Aviso interno validado
- [ ] Fallos corregidos

## Día 5
- [ ] Revisión de tiempos y esperas
- [ ] Revisión de textos finales
- [ ] Documentación mínima cerrada
- [ ] Criterio operativo definido
- [ ] Backlog v2 priorizado
