# Resumen ejecutivo · ORQUESTA v2 · Control operativo y reporting v1

## Qué es
Tercer caso de uso formal de ORQUESTA v2 para el pilar de reporting y control.

## Para qué sirve
Sirve para dar visibilidad real a la operación, detectar bloqueos y gobernar procesos con datos útiles.

## Qué deja resuelto
- procesos a controlar
- estados y eventos
- métricas mínimas
- alertas
- dashboard operativo
- vista ejecutiva
- rutina de revisión

## Qué no hace todavía
No deja aún el dashboard técnico montado ni las integraciones cerradas. Eso corresponde a la implantación siguiente.

## Valor para Orquesta
Este caso convierte la operación en algo gobernable, no opaco. Es la base para escalar sin perder control.

## Siguiente movimiento recomendado
Conectarlo con captación y onboarding para tener una capa de control transversal.
