# ORQUESTA v3 · Sprint de implementación real · Captación v1

## Qué es este paquete
Este paquete convierte el pilar de Captación de ORQUESTA en una unidad de implantación clara, vendible y ejecutable.

No describe solo ideas.
Describe un sprint real de 5 días para dejar funcionando un sistema de captación de extremo a extremo.

## Objetivo
Dejar operativa una primera versión real de Captación capaz de:

- recibir leads reales
- guardarlos correctamente
- clasificarlos
- disparar respuesta automática
- avisar internamente
- registrar seguimiento
- evitar duplicados básicos
- quedar lista para operar con estabilidad razonable

## Tipo de uso recomendado
Este paquete está pensado para:
- implantación interna de ORQUESTA
- presentación comercial a cliente
- ejecución de sprint sobre stack Google + n8n
- base de una oferta de intervención de 5 días

## Resultado esperado
Al cerrar este sprint, el cliente debe tener una captación v1 funcionando de punta a punta, no solo diseñada.
