# Alcance y resultado esperado

## Alcance
Este sprint cubre la implantación de una versión v1 real del sistema de Captación de ORQUESTA sobre un stack pragmático basado en:

- Google Forms
- Google Sheets
- Gmail
- n8n

## Qué incluye
- conexión de la entrada real
- configuración del workflow productivo
- control anti-duplicados
- respuesta automática al lead
- aviso interno
- registro de seguimiento
- prueba real extremo a extremo
- cierre mínimo operativo

## Qué no incluye por defecto
- CRM comercial completo
- scoring avanzado por IA multi-variable
- enriquecimiento externo de leads con proveedores de pago
- analítica avanzada multicanal
- cuadro de mando ejecutivo final
- hardening enterprise completo

## Resultado esperado
Al finalizar, el cliente debe tener una capacidad real de captación operando con una lógica clara:

1. el lead entra
2. el sistema lo procesa
3. el sistema responde
4. el sistema registra
5. el equipo recibe señal
6. el proceso queda trazado

## Resultado de negocio esperado
- menos tiempo manual de entrada
- más velocidad de respuesta
- mejor orden de datos
- menor pérdida de leads por olvido
- mejor base para seguimiento comercial posterior
