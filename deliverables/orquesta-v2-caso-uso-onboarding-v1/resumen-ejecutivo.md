# Resumen ejecutivo · ORQUESTA v2 · Onboarding v1

## Qué es
Segundo caso de uso formal de ORQUESTA v2 para el pilar de onboarding.

## Para qué sirve
Sirve para convertir una venta en un arranque limpio, rápido y gobernable.

## Qué deja resuelto
- trigger de inicio
- flujo de onboarding
- checklist mínima
- estados operativos
- automatizaciones prioritarias
- KPIs
- riesgos y controles

## Qué no hace todavía
No deja aún una implantación cerrada por tipo de servicio. Eso corresponde a la siguiente iteración.

## Valor para Orquesta
Este caso refuerza la parte más delicada tras vender: que el cliente entre bien y que operación no arranque a ciegas.

## Siguiente movimiento recomendado
Bajarlo a un servicio concreto y conectarlo con CRM, Drive, Docs y automatización.
