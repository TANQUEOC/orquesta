# ORQUESTA v3 · Handoff técnico · Onboarding → Control operativo y reporting v1

## Qué es este paquete
Este paquete define la unión técnica y funcional entre los pilares de Onboarding y Control operativo y reporting en ORQUESTA.

Su propósito es evitar que el arranque del cliente quede desconectado de la capa de visibilidad y seguimiento operativo.

## Objetivo
Dejar definido un handoff claro, trazable y automatizable entre:
- el arranque real del cliente en onboarding
- y su entrada en la capa de control operativo y reporting

## Qué resuelve
- evita que el onboarding termine en un vacío operativo
- define qué evento dispara la entrada en control
- define qué datos deben pasar
- define qué estados cambian
- deja una base técnica para automatizar el traspaso

## Contenido del paquete
- `handoff-funcional.md`
- `contrato-de-datos.md`
- `maquina-de-estados.md`
- `flujo-tecnico.md`
- `checklist-implantacion.md`

## Resultado esperado
Al usar este paquete, ORQUESTA debe poder conectar Onboarding y Control como una cadena operativa continua y visible.
