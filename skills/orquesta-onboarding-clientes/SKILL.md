# Orquesta Onboarding de Clientes

Usa esta skill cuando el problema principal empiece justo después de vender.

Su foco es convertir una venta en una puesta en marcha limpia, rápida y controlada.

## Cuándo usarla

Actívala cuando el usuario pida algo como:

- organizar el onboarding de nuevos clientes
- evitar caos tras el cierre comercial
- pedir datos o accesos al cliente
- automatizar emails de bienvenida
- crear checklist de arranque
- repartir tareas internas tras una venta
- reducir tiempo hasta primer valor

## Qué resuelve

Diseña un proceso de incorporación con estas capas:

1. confirmación de cierre
2. creación del expediente del cliente
3. solicitud de datos y accesos
4. kickoff
5. configuración interna
6. primeras entregas o hitos
7. seguimiento de primeros días
8. transición a operación normal

## Entradas mínimas

Si faltan, pide solo esto:

- tipo de servicio o producto vendido
- qué debe ocurrir en la primera semana
- qué datos o accesos necesita el equipo
- qué herramientas usa la operación
- quién es responsable de cada fase

## Método de trabajo

### 1. Define el resultado del onboarding

Aclara qué significa “onboarded” en ese negocio:

- cuenta creada
- acceso recibido
- kickoff hecho
- primer entregable lanzado
- primera campaña activa
- primer valor entregado

### 2. Mapea el proceso real

Ordena el recorrido desde el cierre:

- trigger de venta
- creación de ficha o proyecto
- mensaje de bienvenida
- formularios o documentos
- checklist interna
- reuniones
- hitos
- cierre del onboarding

### 3. Detecta fricciones

Busca especialmente:

- información incompleta
- tareas sin dueño
- esperas entre equipos
- cliente perdido o confuso
- accesos pedidos tarde
- exceso de pasos manuales
- falta de visibilidad del estado

### 4. Diseña el flujo objetivo

Cada paso debe incluir:

- trigger
- acción
- sistema
- responsable
- SLA o plazo
- criterio de completado

### 5. Define control y escalado

Incluye siempre:

- checklist mínima
- estados del onboarding
- documentos y accesos obligatorios
- alertas por bloqueo
- momentos de intervención humana
- criterio de handoff a operación

## Salidas esperadas

Cuando uses esta skill, entrega normalmente:

1. definición de onboarding exitoso
2. flujo propuesto de punta a punta
3. automatizaciones prioritarias
4. tareas humanas necesarias
5. checklist base
6. KPIs y SLAs
7. riesgos
8. siguiente paso de implantación

## KPIs base

Usa los que encajen:

- tiempo desde venta hasta kickoff
- tiempo hasta primer valor
- porcentaje de onboarding completado en plazo
- bloqueos por falta de accesos o datos
- tickets o incidencias en primera semana
- churn temprano o insatisfacción inicial

## Reglas

- No confundas onboarding con soporte.
- No dejes tareas críticas sin responsable explícito.
- Prioriza claridad para el cliente y orden interno a la vez.
- Si el negocio es pequeño, diseña una versión ligera antes que un monstruo procedural.
- Cada automatización debe dejar trazabilidad del estado.

## Formato de salida

Responde en tono práctico y de operaciones.

Prioriza:

- flujo
- responsables
- checklist
- SLAs
- quick wins
- riesgos reales
