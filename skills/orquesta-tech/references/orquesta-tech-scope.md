# Alcance de ORQUESTA Tech

## Esta skill sí cubre
- arquitectura técnica
- integraciones
- n8n / Make
- APIs y webhooks
- Supabase y datos
- memoria y RAG
- observabilidad y evals
- control técnico de producción
- despliegue de sistemas agentic

## Esta skill no es la principal para
- estrategia comercial pura
- copy y narrativa
- creatividad de marca
- definición de oferta no técnica

## Relación con otras skills
- trabaja bien con `orquesta-captacion-leads` cuando hay que aterrizar captación en stack real
- trabaja bien con `orquesta-onboarding-clientes` cuando el onboarding requiere datos, estados e integraciones
- trabaja bien con `orquesta-control-operativo-reporting` cuando hay que diseñar señales, métricas y alertas
- puede apoyar a `orquesta-router` como skill técnica de ejecución
