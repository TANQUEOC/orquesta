# Cuellos de botella típicos en pymes de servicios

## Los más frecuentes
- entra trabajo sin contexto suficiente
- se vende una cosa y se entrega otra
- onboarding pobre o tardío
- nadie sabe el estado real de cada cliente
- el fundador decide demasiado y tarde
- tareas sin dueño claro
- bloqueos invisibles
- demasiada herramienta para poco proceso
- demasiada operación manual sin trazabilidad

## Regla práctica
Antes de automatizar, identifica si el bloqueo real es:
- comercial
- de arranque
- de control
- de operación
- de capacidad del equipo
