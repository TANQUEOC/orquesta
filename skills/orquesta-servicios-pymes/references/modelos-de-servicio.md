# Modelos de servicio en pymes

## Tipos habituales

### Proyecto cerrado
- inicio y fin claros
- entregables concretos
- riesgo de mala definición inicial

### Servicio recurrente
- relación continua
- riesgo de desorden por acumulación
- necesita estados, SLA y continuidad

### Soporte / incidencias
- entrada imprevisible
- riesgo de saturación y pérdida de prioridad
- necesita triage y control diario fuerte

### Modelo mixto
- combina proyecto + recurrente + soporte
- exige distinguir bien flujos y responsables

## Regla útil
Si el negocio mezcla modelos, no uses un único circuito para todo.
