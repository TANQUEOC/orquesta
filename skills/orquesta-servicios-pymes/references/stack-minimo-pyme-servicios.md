# Stack mínimo para pyme de servicios

## Principio
Una pyme de servicios necesita más continuidad que sofisticación.

## Stack base razonable
- formulario o entrada simple
- sheet o base ligera
- email
- automatizador tipo n8n
- docs/checklists claros
- dashboard simple

## Qué evitar al principio
- CRM pesado si aún no hay proceso claro
- demasiadas vistas y estados inútiles
- automatizaciones difíciles de mantener
- integración compleja sin necesidad real

## Regla final
Mejor una columna captación → onboarding → control → operaciones que funcione de verdad, que una arquitectura bonita imposible de sostener.
