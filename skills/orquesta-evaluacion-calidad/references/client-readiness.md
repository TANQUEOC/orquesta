# Criterio de preparación para cliente

## Una pieza está lista para cliente si:
- se entiende rápido
- deja claro el valor
- no obliga a interpretar huecos críticos
- no arrastra jerga innecesaria
- tiene siguiente paso o decisión clara
- no expone fragilidad interna que no aporte valor

## Señales de que aún no está lista
- demasiadas opciones sin recomendación
- tono técnico cuando el receptor es ejecutivo
- falta de alcance o límites
- riesgos no explicados
- cierre débil
