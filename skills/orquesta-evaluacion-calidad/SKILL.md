# Orquesta Evaluación de Calidad

## Para qué existe
Esta skill existe para revisar críticamente el trabajo antes de darlo por bueno.

No sirve para criticar por criticar.
Sirve para detectar flojedades, ambigüedades, huecos, riesgos o exceso de ruido antes de entregar algo importante.

## Cuándo usarla
Actívala cuando el usuario pida algo como:

- revisa esta propuesta
- dime si esto está bien
- audita este entregable
- evalúa esta respuesta
- cómo de sólido está este plan
- qué le falta a este documento
- esto está listo para cliente o no

## Qué resuelve
Aplica una revisión estructurada sobre estas capas:

1. claridad
2. utilidad real
3. accionabilidad
4. rigor
5. foco y priorización
6. adecuación al destinatario
7. riesgos o huecos
8. criterio de “listo / no listo”

## Entradas mínimas
Si faltan, pide solo esto:

- qué pieza hay que revisar
- para quién va dirigida
- qué objetivo debe cumplir
- qué nivel de exigencia tiene
- si hay alguna preocupación concreta

## Método de trabajo

### 1. Aclarar la función de la pieza
Antes de evaluar, deja claro:
- qué pretende resolver
- para quién está escrita
- qué decisión o acción debe facilitar

### 2. Evaluar por criterios útiles
No uses juicio difuso. Evalúa al menos:
- claridad
- utilidad
- estructura
- foco
- consistencia
- rigor
- capacidad de ejecución

### 3. Buscar fallos reales
Detecta especialmente:
- ambigüedad
- ruido o relleno
- opciones sin criterio
- pasos no ejecutables
- falta de riesgos
- tono poco adecuado al destinatario
- cierre débil o siguiente paso poco claro

### 4. Dar veredicto
La salida debe terminar en una de estas tres:
- listo
- casi listo, con ajustes concretos
- no listo, con causa clara

### 5. Mejorar sin reventar
Si algo está casi bien, corrige lo mínimo necesario para subir la calidad sin rehacer por deporte.

## Salidas esperadas
Cuando uses esta skill, entrega normalmente:

1. pieza evaluada
2. objetivo de la pieza
3. criterios de revisión
4. puntos fuertes
5. fallos o huecos
6. veredicto
7. ajustes prioritarios

## Reglas
- No llames “bien” a algo solo porque suena completo.
- No confundas longitud con calidad.
- Si falta criterio, dilo.
- Si falta ejecución, dilo.
- Si el cierre es débil, arréglalo.
- La evaluación debe ayudar a mejorar, no solo señalar defectos.

## Formato de salida
Responde con mentalidad de revisión profesional.

Prioriza:
- veredicto claro
- criterio usado
- fallos reales
- mejoras concretas
- decisión de listo / no listo
